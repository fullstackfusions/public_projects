```bash

# View logs

docker-compose down
```

## 🔧 Local Development

### 1. Start Redpanda
```bash
docker-compose up -d redpanda
# Wait for health check: docker-compose ps redpanda
```

### 2. Start API
```bash
cd backends/marketplace-py
pip install -r requirements.txt
KAFKA_BOOTSTRAP=localhost:19092 uvicorn app.main:app --port 8006 --reload
```

### 3. Start Consumer
```bash
cd backends/marketplace-py/consumer
pip install -r requirements.txt
KAFKA_BOOTSTRAP=localhost:19092 KAFKA_GROUP_ID=payment-service-v1 python payment_consumer.py
```

### 4. Start Frontend
```bash
cd frontends/customer-portal
npm install
npm run dev
```

## 🧪 Testing

```bash

```

### Run Test Script
```bash

```

### Check Payment Database
```bash
# Docker
docker exec -it payment-consumer sqlite3 /data/payments.db "SELECT * FROM payments;"

# Local
sqlite3 backends/marketplace-py/consumer/payments.db "SELECT * FROM payments;"
```

### View Kafka Topics
```bash
docker exec -it redpanda rpk topic list
docker exec -it redpanda rpk topic consume orders.created
```

### View Consumer Groups
```bash
docker exec -it redpanda rpk group list
docker exec -it redpanda rpk group describe payment-service-v1
```

## 📝 API Endpoints

### POST /orders
Create a new order

**Request:**
```json
{
  "user_id": "user_1",
  "amount_cents": 1999
}
```

**Response:**
```json
{
  "order_id": "ord_user_1_1999",
  "status": "created"
}
```

### GET /health
Health check

**Response:**
```json
{
  "ok": true,
  "service": "marketplace-api"
}
```

## 📡 Kafka Events

### Topic: orders.created

**Schema:** OrderCreatedEventV1

**Example:**
```json
{
  "order": {
    "order_id": "ord_user_1_1999",
    "user_id": "user_1",
    "amount_cents": 1999
  }
}
```

**Producer:** marketplace-api
**Consumers:** payment-service (group: payment-service-v1)

## 🎯 Key Concepts

| Concept | Implementation | Location |
|---------|----------------|----------|
| **OpenAPI** | Auto-generated by FastAPI | http://localhost:8006/docs |
| **AsyncAPI** | Event contract spec | `backends/marketplace-py/asyncapi.yaml` |
| **Routing** | Kafka topic `orders.created` | Producer: `app/main.py` |
| **Consumer Group** | `payment-service-v1` | Consumer: `consumer/payment_consumer.py` |
| **Data Ownership** | Orders: API, Payments: Consumer | Separate databases |

## 🐛 Troubleshooting

### API not starting
```bash
# Check if Redpanda is running
docker-compose ps redpanda

# Check API logs
docker-compose logs marketplace-api
```

### Consumer not processing events
```bash
# Check consumer logs
docker-compose logs payment-consumer

# Check if consumer is connected to correct Kafka
# Should see: Connected to Kafka at redpanda:9092
```

### Events not appearing in Kafka
```bash
# Check Redpanda health
docker exec -it redpanda rpk cluster health

# List topics
docker exec -it redpanda rpk topic list

# Should see: orders.created
```

### Frontend can't connect to API
```bash
# Check environment variable
echo $VITE_MARKETPLACE_API_URL

# Should be: http://localhost:8006 (or empty to use default)
```


### Frontend
```bash
VITE_MARKETPLACE_API_URL=http://localhost:8006  # API base URL
```

## 💡 Tips

1. **Always start Redpanda first** when running locally
2. **Check consumer logs** to verify events are processed
3. **Use OpenAPI docs** at `/docs` for interactive testing
4. **View AsyncAPI spec** to understand event contracts
5. **Scale consumers** by running multiple instances with same `KAFKA_GROUP_ID`

## 🎓 Learning Path

2. **Intermediate**: Open `/docs` → Test API directly → Check consumer logs
3. **Advanced**: Read AsyncAPI spec → Scale consumer → Explore Kafka topics
